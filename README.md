# Decoder.java
this repository contains a core Java exercise demonstrating how the Java Virtual Machine (JVM) interprets and calculates different numerical bases and Unicode characters.
~~~
Code Structure & Concepts

The Decoder.java program declares integers using machine-level base systems, adds them together, and outputs the result to prove that the JVM automatically converts them back to human-readable Base-10 (decimal) numbers upon printing.
Binary Literals (Base-2): Declared using the 0b prefix.
int a = 0b1010; stores the decimal value 10.
Hexadecimal Literals (Base-16): Declared using the 0x prefix.
int b = 0xff; stores the decimal value 255.
Octal Literals (Base-8): Declared using the 0 prefix.
int c = 010; stores the decimal value 8.
Unicode Literals: Declared using the \u escape sequence inside single quotes.
char symbol = '\u0024'; stores the hexadecimal ID for the dollar sign ($).
~~~
